# 03 Design System

Orbit's design system prioritizes a clean, modern, and highly interactive user experience.

## Core Technologies
- **Tailwind CSS v4**: Utilizes CSS-first configuration and custom design tokens in `globals.css`.
- **shadcn/ui**: Unstyled, accessible components customized to fit Orbit's aesthetic.
- **Framer Motion**: For fluid micro-interactions, layout transitions, and page animations.
- **Lucide React**: Consistent iconography suite.
- **Radix UI**: Accessible primitives underlying shadcn/ui components.

## Theming
- The design system will support dark/light modes.
- Utilizes CSS variables for semantic coloring (e.g., `--primary`, `--background`, `--muted`).
