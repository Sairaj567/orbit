# 13 Roadmap

## Milestone 1: Foundation (COMPLETED)
- Monorepo setup (Turborepo)
- React / NestJS initialization
- Database connection and core schema
- Docker containers for Dev and Prod

## Milestone 2: Design System (IN PROGRESS)
- Tailwind v4 setup
- shadcn/ui integration
- Core layouts (Sidebar, Header, Dashboard skeleton)

## Milestone 3: Database & API Foundation
- Expand Prisma Schema (Tasks, Habits, Notes)
- Basic CRUD operations via NestJS
- Request validation using Zod/Class-validator in `@orbit/shared`
- **Completed Task Engine** (Milestone 3.1 - 3.3)

## Milestone 4: The Projects Domain (Next Major Hub)
- Implement `Project` and `Resource` Prisma schema
- Build Project Dashboard and Global Navigation
- Associate existing Tasks with Projects

## Milestone 5: Feature Implementation
- Habits module UI & Logic (scoped to Projects)
- Notes module UI & Logic (scoped to Projects)

## Milestone 5: Gamification & Analytics
- XP, Levels, and Achievements
- Productivity analytics dashboard

## Milestone 6: Real-time & Polish
- WebSockets integration
- Framer motion animations
- Performance audits and load testing
